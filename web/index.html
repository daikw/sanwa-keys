キー設定

キーボード・フットペダル本体の割り当てを変更します。

接続デバイス

未接続

デスクトップ版Chrome / Edgeで開き、USBデバイスを選択してください。

接続すると現在の設定を読み出します。

キーの割り当て

変更する入力だけ記入してください。空欄は現在の設定を保持します。番号は本体の設定スロットです。

入力現在の設定新しい設定

例: ctrl+shift+a、cmd+f13、enter。

変更内容

    変更はありません。

    適用前の全設定をファイルに保存してから書き込みます。

    バックアップと復元

    CLIと共通のJSON形式です。復元ファイルを読み込んでも、適用するまでは本体を変更しません。

    対応機種・利用上の注意

    400-MA214BK（3ペダル）/ 400-SKB081（6キー）

    このPCにUSB接続したデバイスを操作します。ほかのPCに接続した機器は、そのPCのブラウザで開いてください。Safari・FirefoxはWebHIDに対応していません。Linuxではhidrawへのアクセス権限が必要です。

    書き込みにはファイル保存APIも必要です。保存を取り消した場合は書き込みません。CLIや他の設定ツールと同時に操作しないでください。

    通信エラーや切断が起きたら、接続し直して設定を確認してください。部分的に変更された場合は保存したファイルから復元できます。

    複数ステップのマクロ・照明・ファームウェア更新は対象外です。対応状況はブラウザ版の検証記録をご覧ください。

    サンワサプライ・PCsensorとは独立したOSSです。設定値はサーバーへ送信しません。

    使えるキー名

    修飾キーと通常キー1つを + でつなぎます。修飾キーだけの設定もできます。

    記号はキー名で指定します。 たとえば cmd+; は cmd+semicolon と入力してください。

    入力例

    • cmd+semicolon — Command + セミコロン
    • ctrl+shift+a — Ctrl + Shift + A
    • f13、enter — キー単独

    文字・数字・ファンクションキー

    a〜z、0〜9、f1〜f24。大文字・小文字は区別しません。

    修飾キー

    ctrl、shift、alt、cmd。super と win は cmd と同じ左GUIキーです。

    右側を指定する場合: rctrl、rshift、ralt、rcmd。別名: lctrl、lshift、lalt、lmeta、rmeta。

    記号キーの名前

    記号はUS配列での目安です。実際の文字入力はPCのキーボード配列に従います。

    記号入力する名前
    ;semicolon
    ,comma
    .period
    /slash
    -minus
    =equal
    [leftbracket
    ]rightbracket
    \backslash
    'quote
    `grave

    その他のキー

    enter escape（esc） backspace tab space capslock printscreen scrolllock pause insert home pageup delete end pagedown right left down up numlock
